# Auction social graphics

Collage graphics for weekly auction social posts (Matthews Auction OS). Each auction gets a folder named `YYYY-MM-DD-location` (closing date + auction), e.g. `2026-10-21-dublin/`.

Files here are published at `https://<site>/crm/social/<folder>/<file>` so Genie Rocket and Instagram can fetch them by public URL. Nothing on the site links to them, and the path is marked noindex.

Folders are deleted a few weeks after their auction closes.
